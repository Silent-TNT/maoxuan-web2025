# 教员咨询室交互与文案

写每一句文案前，先把自己放到读者的位置，想一遍此刻发生了什么、轮到谁说话。教员的气泡要像坐在对面的人会说的话，输入框要像读者自己会说出的半句话，等待提示要贴着眼前这件事。

## 选中原文后的对话

| 时机 | 文案 |
| --- | --- |
| 圈好一段，打开咨询室 | 你圈的这一段，我们从这儿谈。 |
| 看到输入框，准备开口 | 教员，我读到这儿，想问问… |
| 发出消息，等教员接话 | （低头翻了翻书） |

普通聊天等待时用「莫急，我想一想。」教员回复中的动作贴着正在谈的事，单独成行。用户补充或纠正了一条情况，教员接着这条情况往下说。

选段只随下一条消息发送。该条已发出后收起选段，回复中断后仍可拿着当时那段原文接话。后来又谈到文章时，按读者新说的指代和当前阅读位置理解。

## 等待、接话和中断

| 时机 | 文案或操作 |
| --- | --- |
| 教员还在说，读者想补充 | 教员，我还想补一句… |
| 教员问完一句，等读者回答 | 教员，事情是这样的… |
| 等得久了，还是在想读者说的事 | 这事得想仔细些，你稍坐。 |
| 话在半途断了 | 刚才的话断在这儿了。我接着说。 |
| 读者按下停止 | 好，先停在这儿。你有话，先说。 |
| 读者要刚才没说完的话 | 接着刚才说 |

教员还在说时，读者可以先打下一句。中断后保留已经说到的地方和读者草稿。接话时先回到当时的问题，有能用的旧事实就带回来。读者改口时照他最近一次说的情况谈。事情讲清了就给判断，读者要收尾时可以用一两句理清谈定的事。

## 原文依据

确实用到的原句放在气泡下面，读者可以点到本文核对。查过几处仍找不到贴切的一段，就说「这一轮先就事说，手头没找到贴切的原文。」只想倾诉时专心听，省去查书提示。正文把读者的原话、教员对眼前的判断和《毛选》引文交代清楚。

## 验收

把开场、开口、等待和接话连起来念一遍，听听像不像两个人在说话。选中原文时，输入框的半句话给读者留出说疑问、讲感受或联系眼前事的余地。等待时的动作短一点，像教员看了一眼读者刚递来的那段原文。

试聊时先发一句，再打一半下一句，在教员回答中间按停止。核对草稿还在、重试仍接原问题、前面选中的原文用在该用的那条。再谈几个来回，核对教员能接住读者先前说过的数字和后来的更正。拿一条可信原文和一条仿造的原话各问一次，看气泡及其依据能不能让读者分辨二者。
